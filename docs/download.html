Get started

From clone to
first request.

Rest Tester runs from source on Windows, macOS and Linux. It is free, open source and needs no account - just Python 3.11 or newer.

View on GitHub -> Download source (.zip)

v2.1.0 · GPL-3.0-or-later · Python 3.11+ · Windows · macOS · Linux

01 / INSTALL

Four steps.

Use a virtual environment so the Qt runtime and other dependencies stay isolated from your system Python.

1

Clone

git clone https://github.com/priyankdalal/rest-tester.git then cd rest-tester.

2

Create a venv

python -m venv .venv, then .venv\Scripts\activate on Windows or source .venv/bin/activate on macOS and Linux.

3

Install

pip install -r requirements.txt installs PyQt6, requests, MSAL, PyJWT and cryptography.

4

Run

python run.py opens the workbench. python run_builder.py opens the Catalog Builder on its own.

git clone https://github.com/priyankdalal/rest-tester.git
cd rest-tester
python -m venv .venv
.venv\Scripts\activate          # Windows
source .venv/bin/activate       # macOS / Linux
pip install -r requirements.txt
python run.py
02 / TRY THE DEMO

No API? Use ours.

A dependency-free Store API ships with the repository, together with a catalog that describes it. Every feature works against it.

Quick start guide -> 
python examples/demo_store_server.py            # http://127.0.0.1:8765
python examples/demo_store_server.py --port 9000 --quiet
  1. Start the demo server in a second terminal.
  2. In Rest Tester open Settings → API catalog → Load catalog... and choose examples/store_catalog.json.
  3. Base URLs for the Catalog, Orders and Customers services are pre-filled.
  4. Pick GET /Product in the API Explorer and click Send.
03 / STANDALONE BUILD

Ship it as an app.

Build a self-contained folder with PyInstaller for machines without Python.

pip install -r requirements-dev.txt
pyinstaller --noconfirm --clean RestTester.spec

The build is written to dist/RestTester/. Keep the whole folder together - it contains the Qt runtime. Packaged builds ship without a catalog; the first launch explains how to load or create one. Data folders are created next to the executable, which keeps the app portable.

04 / REQUIREMENTS

What you need.

Python 3.11+

CPython on Windows 10/11, macOS or a desktop Linux distribution.

Runtime packages

PyQt6, requests, msal, msal-extensions, PyJWT and cryptography - all installed by requirements.txt.

Development extras

pytest, pytest-xdist, pytest-timeout and PyInstaller via requirements-dev.txt.
